## 🎨 **Design System**

### **Color Palette**
```
Primary:   Cyan (#06B6D4)    - Headers, accents, tech elements
Secondary: Purple (#A855F7)  - Gradients, highlights
Accent:    Pink (#EC4899)    - Gradient endpoints
Success:   Green (#4ADE80)   - Low risk, safe transactions
Warning:   Yellow (#FACC15)  - Medium risk, caution
Danger:    Red (#F87171)     - High risk, alerts
Alert:     Orange (#FB923C)  - Structural warnings
Tech:      Red (#EF4444)     - Valkey branding
```

### **Typography**
- **Headers**: `font-black` (900 weight) for maximum impact
- **Metrics**: `text-3xl` for visibility
- **Labels**: `uppercase tracking-wider` for tech aesthetic
- **Monospace**: Account IDs, timestamps, status codes

### **Effects**
- **Gradients**: Multi-color flowing backgrounds
- **Borders**: Semi-transparent colored borders (30-50% opacity)
- **Shadows**: `shadow-2xl` for depth
- **Backdrop Blur**: `backdrop-blur-sm` for glass morphism
- **Hover**: `scale-105` transform on interactive elements
